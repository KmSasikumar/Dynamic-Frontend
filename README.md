# Trademark Search App — Dynamic Frontend

**A personal project by K. Sasi Kumar Yadav.** A high-performance trademark search
application built with Next.js — search, filter, and analyze trademark data through
a fast, responsive interface.

## 📌 Project Overview
A robust **Next.js** application engineered with **TypeScript** and **Tailwind CSS**. This project showcases a high-performance trademark search interface, demonstrating distinct capabilities in API integration, state management, and responsive component design. It mimics a real-world legal tech application where users can search, filter, and analyze trademark data.

## 🚀 Key Features
* **Real-Time Search:** Instant data retrieval from a public trademark API using Axios.
* **Deep Linking:** Search queries and filters are synced with the URL, allowing shareable search results.
* **Smart Filtering:** Client-side filtering for trademark status (Live, Dead, Pending) and Owner names.
* **Dual Views:** Toggle between high-density Grid View and detailed List View for data consumption.
* **Responsive Design:** Fully adaptive layout optimized for desktop and mobile legal research.

## 🏗 Tech Stack
* **Framework:** Next.js 15 (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS 4
* **Deployment:** Vercel

## 🛠 Setup Instructions

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/KmSasikumar/Dynamic-Frontend.git
   cd Dynamic-Frontend
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Run the Development Server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to view the app.
